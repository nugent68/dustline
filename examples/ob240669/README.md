# Example: OGLE-2024-BLG-0669

Sightline RA 275.089125, Dec −18.269389 (l 13.2°, b −1.6°), 9′ radius. Photometry:
PS1 grizy + 2MASS JHKs (no DECaPS/VVV coverage at l > 10°). 4,332 stars with XP spectra
fitted; the sightline is inside the red-clump bulge window.

```bash
dustline run 275.089125 -18.269389 --radius 9 --filter I -o extinction_I.csv --plots .
```

(This directory is regenerated by `tools/run_ob240669.py`, which seeds the Gaia/XP
stage from a local cache instead of the ~2 h archive fetch. Numbers are from the v0.8.0
stack: the 900 Å–6 µm model cache with the label-locked per-model dwarf *and giant*
template corrections (`tca602f749`), the sub-grid (R_V, A_V) refinement and the
reddening-injection closure correction of the law (uncorrected median 2.79). Version
history: v0.7.0 R_V = 2.80 ± 0.54 (883 stars), v0.6.0 2.76 ± 0.50 (857) on a grid that
dropped the band corrections at A_V ≠ 0, v0.5.0 2.80 ± 0.46 (895), v0.4.0 2.84 ± 0.48
(946), and the v0.2–0.3 run on the 2500–25000 Å cache 2.88 ± 0.53 (986); clump column
3.27–3.43 throughout. The bulge is the least sensitive field in the example set to the
calibration work — its stars are cool giants at A_V ≈ 3, where the 1/A_V template
residual is small.)

## Result (v0.8.0)

- **R_V = 2.82 ± 0.50** (median ± MAD, 905 stars with A_V ≥ 2; 2.79 before the
  closure correction, which is only +0.03 here — the 1/A_V residual is halved at
  A_V ≈ 3 and the v0.8.0 closure table is itself smaller). Raw by population: giants
  2.64 (N 522), dwarfs 3.14 (N 383); raw by A_V bin 2.91 (2–3, N 566), 2.63 (3–4, N 271),
  2.66 (4–5, N 56). Per-star errors 0.07–0.52.
- **Red-clump anchor:** E(J−Ks) = 0.52 from 1,820 clump-window stars at Ks = 12.65,
  giving A_V = 3.34 ± 0.62 (A_Ks = 0.31) at D_RC = 6.1 kpc.
